# KaosDual Cards

Skylanders card assets for KaosDual-Extended. Artwork may be copyrighted; ensure you have permission before publishing.

## GitHub Pages

Repository Settings > Pages > Deploy from a branch > main / (root).

Paths: `portraits/<filename>.webp`, `cards/<filename>.webp`, and `manifest.json`.

The `manifest.json` contains the asset index. The firmware WebUI must be configured to use the published base URL; uploading images alone does not change the firmware.
